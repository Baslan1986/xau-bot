# Solnerv Attend: دوام محطات الطاقة الشمسية (المرحلة 1)

تطبيق ويب بينزل على الجوال (PWA) للموظفين، ومعه لوحة إدارة. السيرفر FastAPI وقاعدة البيانات SQLite.
كل كود الدوام بهالمجلد، وهو جاهز ينتقل لريبو لحاله.

- **عقد الربط مع SolNerve و Shams:** [`../docs/ATTEND_API.md`](../docs/ATTEND_API.md)
- **ملخص التسليم لمدير المشروع:** [`../docs/SOLNERVE_ATTEND_HANDOFF.md`](../docs/SOLNERVE_ATTEND_HANDOFF.md)

## التشغيل

```bash
cd attend
pip install -r requirements.txt
export ATTEND_SECRET="$(python3 -c 'import secrets;print(secrets.token_hex(32))')"
uvicorn app.main:app --host 0.0.0.0 --port 8000
python3 -m pytest -q   # الاختبارات
```

> ما في أي سر أو كلمة سر بالريبو. كل الأسرار بتنحط كمتغيرات بيئة على السيرفر.
> المتصفح ما بعطي موقع الجوال إلا على HTTPS، فبالإنتاج حط `ATTEND_HTTPS_ONLY=1`.

| متغير | الافتراضي | |
|---|---|---|
| `ATTEND_SECRET` | عشوائي | مفتاح توقيع جلسات الدخول. **إلزامي بالإنتاج** |
| `ATTEND_DB_URL` | `sqlite:///./attend.db` | قاعدة البيانات |
| `ATTEND_PEOPLE_SOURCE` | `local` | `solnerve`: الموظفين والإجازات من SolNerve فقط |
| `ATTEND_SOLNERVE_URL` | — | رابط صفحة الإجازات بـ SolNerve، بيطلع للموظف |
| `ATTEND_INTEGRATION_TOKEN` | — | توكن `/api/integration/*`. إذا ما انحط، الربط مسكّر |
| `ATTEND_NOTIFY_URL` | — | رابط Shams لاستقبال الإشعارات (هو بيوصلها على واتساب) |
| `ATTEND_NOTIFY_SECRET` | — | مفتاح توقيع الإشعارات (HMAC-SHA256) |
| `ATTEND_PROFILES_DIR` | — | مجلد ملفات المحطات (JSON)، بتنقرا عند التشغيل |
| `ATTEND_TICK_SECONDS` | `20` | كل قديش بتشتغل التذكيرات وتوصيل الإشعارات |
| `ATTEND_HTTPS_ONLY` | `0` | `1` بالإنتاج |
| `ATTEND_OFFLINE_MAX_HOURS` | `72` | أقدم حركة بتنقبل بعد ما انحفظت بدون إنترنت |

## ملف المحطة: معيار واحد لكل محطة

كل محطة بتنوصف بملف واحد: `tenantId` و`plantId` والمنطقة الزمنية واللغة والحدود والشفتات والسماح وأقل عدد بالشفت.
ما في اسم أو رقم أو إحداثية أو توقيت محطة مكتوب بالكود. شوف المثال [`profiles.example/plant.json`](profiles.example/plant.json).
الملف بينحط بثلاث طرق: من لوحة الإدارة، أو من مجلد `ATTEND_PROFILES_DIR`، أو عن طريق `PUT /api/integration/plants`.
في اختبار بيثبت إن محطة ثانية بتشتغل بدون أي تعديل بالكود، مع إنها من جهة ثانية وبتوقيت ثاني وبثلاث شفتات بدل اثنين.

## اللي انبنى

**الموظف**
- كبسة وحدة بتتغير حسب الحالة: وصول، دخول، خروج، انطلاق. الوصول والدخول ما بنقبلوا إلا جوا الحدود.
- **بدون إنترنت:** الحركة بتنحفظ على الجوال وبتنرفع لحالها بعدين.
- جدوله، ساعاته، وعداد الالتزام بالوقت.
- طلب إجازة أو مغادرة مع إنترلوك البديل. بوضع `solnerve`، الطلب بينعمل من SolNerve.
- زر SOS. موقعه بنتتبع بس وهو بالدوام.

**الإدارة:** متابعة مباشرة مع خريطة، الطلبات، الموظفين وصيغ أسمائهم، الأسماء اللي بحاجة تأكيد، الفرق والجدول (مع تنبيه نقص التغطية)، ملفات المحطات، وتقرير ساعات (بدون أي مبالغ).

**أوقات إنسانية:** اللي بيوصل خلال السماح بينحسب على الوقت (10:10 = 10:00 لما السماح 10 دقايق)، ونفس الإشي حوالين نهاية الشفت. برا السماح، بينحسب الوقت الفعلي كامل.
**الخطوة الفايتة بتشتغل مرة وحدة بأقرب وقت:** إذا نسي الموظف يسجل وصول أو انطلاق، بيوصله تذكير واحد بس. ونفس الإشي للفحص اليومي للتغطية لو السيرفر كان طافي أيام.

**الإشعارات:** ما في أي تطبيق مراسلة جوا Attend. كل إشعار بيتخزن بالتطبيق، وإذا `ATTEND_NOTIFY_URL` محطوط بينبعث موقّع لـ Shams، وShams بيوصله على واتساب. إذا فشل الإرسال، بينعاد لحد ما ينجح، وكل إشعار إله رقم ثابت عشان ما يتكرر.

**الأسماء:** كل شخص إله صيغ اسم معروفة (الاسم الأول، اللقب مع الاسم، اسم العيلة). المطابقة حرفية بعد تنظيف الحركات والهمزات بس. الصيغة اللي مش معروفة بتصير سؤال للإدارة، والنظام ما بيخمّن أبداً.

**الخصوصية:** ما في بيانات موظفين بالسجلات (logs). تقرير الساعات وواجهة الحضور لـ SolNerve ما فيهم أرقام هواتف ولا مبالغ، والحضور بينبعث لـ SolNerve بـ `personRef` بدل الاسم.
